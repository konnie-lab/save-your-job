# Save Your Job

A short playable by Konnie-Lab about work, AI, and staying human under pressure.

[Play Save Your Job](https://konnie-lab.github.io/save-your-job/)

This repository hosts the standalone game build. `index.html` contains the runtime, artwork, and audio; no installation or build step is needed to play.

GitHub Pages publishes the root of the `main` branch. To update the game, replace `index.html` with the latest standalone build and push to `main`.
