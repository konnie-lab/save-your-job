# Save Your Job

A short playable by Konnie-Lab about work, AI, and staying human under pressure.

[Play Save Your Job](https://konnie-lab.github.io/save-your-job/)

This repository hosts the standalone game build. `index.html` contains the runtime, artwork, and audio; no installation or build step is needed to play.

GitHub Pages publishes the root of the `main` branch. To update the game, replace `index.html` with the latest standalone build and push to `main`.

[Portfolio and contacts](https://konnie-lab.github.io/playables/)

## View counter

The public game sends one pageview request to `konnie-lab.goatcounter.com` per page open, including reloads. It uses a fixed page path and sends only the referring site's origin, excluding its page path and query parameters. Session tracking is disabled; no cookies or game events are sent. Local files, localhost previews, other site paths, and automated browsers do not send requests. A blocked or unavailable counter does not prevent the game from loading.

Statistics are available to the account owner at [GoatCounter](https://konnie-lab.goatcounter.com/). The selected account settings retain referrers and country totals; browser/system, screen size, region, language, and individual pageview records are disabled. Country is derived by the service from the request IP address. The game's `ns=true` requests bypass session tracking even if the account's Sessions checkbox is enabled. See [GoatCounter's privacy policy](https://www.goatcounter.com/help/privacy) for the service's handling of requests.
